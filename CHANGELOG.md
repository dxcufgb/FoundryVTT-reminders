# Changelog

## 1.1.1

- Optional support for Dxcufgb's Debug Recorder: while a GM records, the module adds a snapshot of its runtime state (Reminder list counts by kind, the current combat's eligible creatures and reminder counts, cards in chat, caught errors) and breadcrumbs for turn checks, posted cards, Use buttons, legendary resistance and list changes. It holds only counts, on/off values and the module's own fixed options, never creature, item or player names or the list's text. Without the recorder nothing changes.
